# Changelog

## 2.0.0 (26H2)

- Open-source release under MIT.
- Modular source tree; `dist/worker.js` is generated by `npm run build`.
- Provider adapters for language model, speech-to-text and text-to-speech, configurable by base URL and format.
- Interface languages: English (default), Thai, Chinese.
- Self-hosted Liquid Glass SDK and React; no third-party CDN.
- Server-side speech-to-text; hold-to-talk mode in Live.
- Clear provider error messages in chat with a retry button.
- Build number and id shown in Settings.
- Documentation: README in English, Thai, and Chinese; a no-terminal deployment guide (DEPLOY.md); architecture decision records in contributing/decisions/.
- Documentation checks run as part of `npm test`.
